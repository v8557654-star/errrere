# Minecraft Mods Website 🎮

Современный, адаптивный и быстрый сайт для распространения модов на Minecraft. Включает в себя темную/светлую тему, поиск в реальном времени, фильтрацию по версиям и лоадерам, а также оптимизированную загрузку ресурсов.

## ✨ Основные возможности

- 🌗 **AMOLED Темная тема** и переключатель тем.
- 📱 **Полная мобильная адаптивность**.
- ⚡ **Ленивая загрузка (Lazy Loading)** изображений для ускорения работы.
- 🔍 **Живой поиск** и фильтрация по тегам/категориям.
- 📥 **Умное скачивание**: выбор версии Minecraft, лоадера (Forge/Fabric/Quilt) и версии мода перед загрузкой.
- ♿ **Доступность (A11y)**: ARIA-атрибуты, управление с клавиатуры, высокий контраст.
- 🎨 **Визуальные эффекты**: плавные анимации, градиенты, hero-секция.
- 📊 **Статистика**: анимированные счетчики скачиваний и пользователей.

## 🚀 Как захостить сайт через GitHub Pages

Этот сайт статический (HTML/CSS/JS), поэтому его можно бесплатно разместить на GitHub Pages за пару минут.

### Шаг 1: Подготовка репозитория
1. Убедитесь, что ваш код находится в корневой папке репозитория (файлы `index.html`, папки `css`, `js`, `images` и т.д. должны быть видны сразу при открытии репозитория).
2. Если у вас файлы находятся в подпапке (например, `/site`), это нужно будет учесть в настройках ниже.

### Шаг 2: Включение GitHub Pages
1. Перейдите в ваш репозиторий на GitHub.
2. Нажмите на вкладку **Settings** (Настройки) в верхнем меню.
3. В левом боковом меню найдите раздел **Pages**.
4. В разделе **Build and deployment**:
   - **Source**: Выберите `Deploy from a branch`.
   - **Branch**: Выберите ветку (обычно `main` или `master`) и папку `/(root)` (или `/docs`, если вы переместили файлы туда).
   - Нажмите **Save**.

### Шаг 3: Проверка статуса
1. GitHub начнет сборку сайта. Это займет от 1 до 5 минут.
2. Обновите страницу настроек **Pages**. Сверху появится сообщение со ссылкой вида:
   `Your site is live at https://<ваш-username>.github.io/<название-репозитория>/`
3. Перейдите по ссылке, чтобы проверить работу сайта.

### Шаг 4: Настройка домена (Опционально)
Если вы хотите свой домен (например, `mymods.com`):
1. В том же разделе **Pages** в поле **Custom domain** введите ваше имя домена.
2. Нажмите **Save**.
3. Вам потребуется настроить DNS-записи у вашего регистратора домена (обычно это `CNAME` запись).

## 🛠 Локальная разработка

Если вы хотите запустить сайт локально перед публикацией:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЮЗЕРНЕЙМ/ВАШ_РЕПОЗИТОРИЙ.git
   cd ВАШ_РЕПОЗИТОРИЙ
   ```

2. Откройте файл `index.html` в любом браузере.
   > **Совет**: Для корректной работы некоторых функций (например, загрузки внешних JSON или модулей) лучше использовать локальный сервер.
   > Если установлен Python:
   > ```bash
   > python3 -m http.server
   > ```
   > Затем откройте `http://localhost:8000`.
