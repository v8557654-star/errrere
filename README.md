# MineMods — сайт модов для Minecraft 🎮

Современный, адаптивный и быстрый сайт для поиска и скачивания модов на Minecraft.
Написан на **чистом HTML/CSS/JS** — сервер не нужен, всё работает прямо в браузере.

> 📁 **Статический сайт лежит отдельно от всего проекта — в папке [`docs/`](docs/).**
> Это самодостаточная папка: её можно копировать куда угодно и публиковать как есть.
> Старая Flask-версия (`app.py`, `templates/`) остаётся в корне просто как архив.

## ✨ Возможности

- 📦 **Каталог модов** с живым поиском, фильтрами (категория, версия MC, теги) и сортировкой.
- 🌍 **Живой поиск по Modrinth** со **скачиванием прямо на сайте**: у каждой карточки есть кнопка
  быстрой загрузки, а на странице проекта — список версий с фильтрами по версии MC и лоадеру.
  Файлы качаются напрямую с CDN Modrinth, без перехода на внешний сайт.
- 🦊 **Живой поиск по GitHub** — open-source проекты Minecraft через API GitHub.
- 🎨 **SVG-иконки интерфейса** (контурные, в стиле Lucide) вместо эмодзи: меню, кнопки,
  статистика, вкладки — всё масштабируется и красиво в любой теме.
- 🌗 **7 тем оформления** (зелёная, синяя, фиолетовая, оранжевая, розовая, светлая, AMOLED) —
  переключаются мгновенно и сохраняются в браузере.
- 👤 **Демо-аккаунт без сервера**: регистрация, профиль, загрузка модов, избранное,
  подписки, личные сообщения, достижения и уведомления — всё хранится в `localStorage` браузера.
- ⬇ **Умное скачивание**: выбор версии Minecraft, лоадера (Forge/Fabric/NeoForge) и версии мода.
- ⚖️ **Сравнение модов**: отметь до трёх модов на карточках (кнопка «+») и сравни их характеристики
  в наглядной таблице — категория, версии, автор, скачивания, лайки, просмотры, теги и описание.
- 🎲 **Случайный мод**: кнопка в hero-секции открывает случайный мод из каталога.
- 🕘 **Недавно просмотренные**: список последних открытых модов хранится в браузере и показывается
  на главной странице.
- 🔗 **Поделиться**: кнопка на странице мода копирует ссылку (или открывает системное меню «Поделиться»).
- 📱 Полная мобильная адаптивность, анимации, счётчики статистики, лайтбокс для скриншотов.
- ♿ Доступность: skip-link, ARIA-атрибуты, поддержка клавиатуры.

## 🚀 Локальный запуск

```bash
cd docs
python3 -m http.server 8080
# открой http://localhost:8080
```

Либо просто открой `docs/index.html` в браузере.

## 🌐 Хостинг на GitHub Pages

Папка `docs/` — стандартный способ публикации статического сайта:

1. Открой репозиторий на GitHub → **Settings** → **Pages**.
2. **Source**: `Deploy from a branch`.
3. **Branch**: выбери ветку (например, `main`) и папку **`/docs`** → **Save**.
4. Через 1–5 минут сайт будет доступен по адресу
   `https://<username>.github.io/<репозиторий>/`.

## 🔧 Как редактировать

- Тексты и вёрстку страниц — прямо в `docs/*.html`.
- Демо-каталог модов (главная, избранное, лента, авторы) — массив `MM.CATALOG`
  в `docs/static/js/site.js` (и дубль-источник в `static/js/site.js`).
- Стили и скрипты правятся в `static/` (корень проекта), затем нужно запустить
  `python3 build_static.py` — скрипт пересоберёт страницы и скопирует ресурсы в `docs/`.

## ⚠️ Про демо-режим

Так как сайт статический, аккаунты, лайки, моды и сообщения сохраняются только в
браузере пользователя (`localStorage`). Поиск по Modrinth и GitHub — настоящий,
через их публичные API. Для полноценной работы с базой данных используй старую
Flask-версию (`app.py`) или подключи любой бэкенд.
